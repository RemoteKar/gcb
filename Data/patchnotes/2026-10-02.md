# 게임캐릭터배틀

게임진행:
	부활:
		대기시간: 20초에서 사망마다 10초씩 더 증가 -> 30초에서 사망마다 2배 (30초 / 60초 / 120초 / 240초)
		최소 대기시간: 20초 -> 30초
		처치당 다음 부활 대기시간 감소: 5% -> 15%
		부활 불가 시점: 8라운드 -> 게임 시작 240초 후 (모두가 증강 4개를 받는 시점)
		부활 불가가 되면 대기 중이던 부활도 취소됩니다
		부활 위치가 맵 밖 먼 곳으로 잡히던 버그 수정
	증강 획득:
		획득 주기: 75초 -> 60초
		(신규) 증강 예약이 게임이 끝나도 유지되어 다음 게임에서 같은 순서로 다시 구매합니다
		(신규) 증강 선택 창에 "예약 전부 해제" 버튼 추가
	능력치:
		(신규) 궁극기 가속: 궁극기에만 적용되는 가속. 스킬가속과 더해 궁극기 재사용대기시간을 줄입니다
		(신규) 적응형 능력치: 1당 공격력 0.5 또는 타격력 1. 추가 공격력과 타격력 중 높은 쪽으로 들어갑니다
		(부가설명: 추가 공격력과 타격력의 절반을 비교하고, 같으면 공격력)
	캐릭터 선택:
		선택한 캐릭터를 다시 눌러도 선택이 해제되지 않던 버그 수정 (해제하면 게임 시작 때 무작위)
		Shift+F로 여는 창: 캐릭터 목록 -> 내 캐릭터 (/캐릭터목록 명령어는 그대로 전체 목록)
	관전 모드:
		(신규) 내 캐릭터 창에 관전 모드 버튼 추가
		켜 두면 다음 게임부터 참가하지 않고 관전만 합니다 (진행 중인 게임에는 영향 없음)
		주 캐릭터 선택은 유지되며, 끄면 다음 게임부터 다시 참가합니다
		(부가설명: 서버가 재시작되면 모두 꺼짐으로 돌아감)

증강:
	방어력 제공량 조정:
		결의: 25 -> 30
		헤르메스의 시미터: 40 -> 35
		마법사의 최후: 45 -> 35
		헤르메스의 발걸음: 55 -> 45
		얼어붙은 건틀릿, 정령의형상, 죽음의 무도, 존야의 모래시계: 60 -> 50
		란두인의 예언, 얼어붙은 심장: 90 -> 70
		가시 갑옷: 130 -> 100
	밤의 끝자락:
		(신규) 메자이의 영혼약탈자를 대체하는 증강
		방어구관통력 20, 최대체력 100
		적의 스킬을 한 번 막아주는 주문 보호막을 얻습니다 (재사용대기시간 45초)
		막은 스킬의 피해와 방해효과가 모두 무효화되며 시간정지도 막습니다
	메자이의 영혼약탈자:
		삭제
	악마의 포옹:
		추가 체력의 타격력 전환: 4% -> 2%
	지배자의 피갑옷:
		추가 체력의 공격력 전환: 4% -> 2%
	모렐로노미콘, 라일라이의 수정홀, 월식, 신비의 폭발:
		쓰는 즉시 다른 스킬로 바뀌는 스킬(롤랑 3번 등)에 발동하지 않던 버그 수정

코어:
	처치 성장:
		(신규) 적 플레이어를 처치할 때마다 코어가 성장합니다
		성장하는 능력치와 최대 횟수는 코어마다 다릅니다 (아래 "처치당" 항목)
		처치 수는 죽어도 유지되고 게임이 끝나면 초기화됩니다
	화살통:
		(신규) 공격속도 30%
		적중 효과가 발동하면 대상을 쫓는 화살을 1발 쏩니다 (처치당 +1발, 최대 7발)
		화살은 6(+2% 추가 공격력)의 피해를 주고 적중 효과를 15%만 적용합니다
		(부가설명: 화살 피해와 적중 효과 모두 발동한 공격의 적중 계수를 곱함)
	아퀼라 투구:
		처치당 강인함 +5 (최대 10회)
	방부:
		처치당 방부의 피해 +10% (최대 10회)
	신호기:
		4초 이상 유지 시 효과 배수: 4배 -> 3배
		처치당 효과 배수 +0.2배 (최대 10회)
	제어 와드:
		처치당 타격력 +5 (최대 20회)
	되감는 시계:
		처치당 스킬가속 +5 (최대 10회)
	심해의 닻:
		방어력: 45 -> 50
		처치당 방어력 +15 (최대 3회)
	심우주 망원경:
		처치당 타격력 +4, 스킬가속 +4 (최대 10회)
	푸른 요람:
		최대체력: 450 -> 200
		처치당 최대체력 +80 (최대 10회)
	번개의 신의 눈:
		처치당 적응형 능력치 +8 (최대 8회)
	맞물린 톱니:
		처치당 이동속도 +5%, 스킬가속 +5 (최대 10회)
	바위의 신의 눈:
		처치당 방어력 +15 (최대 5회)
	황금가지:
		처치당 체력재생 +2 (최대 10회)
	끈:
		처치당 최대체력 +50 (최대 10회)
	불운 보정 주사위:
		처치당 방어력 +10 (최대 8회)
	기적의 큐브:
		전투에서 벗어났을 때 이동속도 증가: 30% -> 75%
		처치당 방어구관통력 +15 (최대 4회)
	반응로 심핵:
		처치당 타격력 +5 (최대 8회)
	시공의 문장:
		처치당 궁극기 가속 +4 (최대 8회)
	비상식량:
		처치당 적응형 능력치 +10 (최대 10회)
	응급 심장:
		최대체력: 300 -> 200
		처치당 총 최대체력 +5% (최대 10회)
	극성 자석:
		주 능력치: 공격력 20 -> 적응형 능력치 20
		처치당 적응형 능력치 +4 (최대 10회)
		(신규) 기본공격뿐 아니라 스킬로 공격해도 발동합니다
		두 적을 공격해야 하는 제한 시간: 6초 -> 5초
		기절: 3초 -> 2초
		재사용대기시간: 6초 -> 30초
		끌려오던 적이 시전자에게 부딪혀 바로 멈추던 버그 수정
	주머니 포로:
		최대체력: 150 -> 100
		처치당 최대체력 +50 (최대 6회)
	작은 원석:
		시작 확률: 4% -> 2%
		실패할 때마다 오르는 확률: 4%p -> 2%p
		처치당 실패 시 오르는 확률 +2%p (최대 10회)
	내연 기관:
		처치당 공격력 +5 (최대 10회)
	슈퍼스타:
		스킬가속: 15 -> 10
		처치당 궁극기 가속 +6 (최대 10회)
	개척의 쓰레기통:
		총 최대체력: 45% -> 30%
		처치당 총 최대체력 +3% (최대 10회)
	무색의 정육면체:
		체력 50% 이하인 적에게 주는 피해 증가: 10% -> 20%
		처치당 방어구관통력 +15 (최대 4회)
	합일의 골조:
		방어력: 60 -> 40
		처치당 방어력 +10 (최대 4회)
	태엽 폭탄:
		주 능력치: 타격력 40 -> 적응형 능력치 40
		폭탄 피해: 80(+120% 타격력) -> 80(+120% 타격력)(+150% 추가 공격력)
		처치당 스킬가속 +10 (최대 4회)
	방부, 제어 와드, 심우주 망원경, 작은 원석:
		쓰는 즉시 다른 스킬로 바뀌는 스킬(롤랑 3번 등)에 발동하지 않던 버그 수정

		(부가설명: 맵에 설치된 짚라인에도 적용, 고정 피해는 줄지 않음)
	그래플링훅:

		(신규) 공중이어도 발밑 1.5블록 안에 땅이 있으면 설치할 수 있습니다

	윙맨 등 히트스캔 탄환이 튕겨나갈 때 궤적이 두 줄로 그려지던 버그 수정
