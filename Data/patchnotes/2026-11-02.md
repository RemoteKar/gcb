# 게임캐릭터배틀

코어:
	공명 회로:
		[신규] 스킬가속 15, 처치당 적응형 능력치 +3 (최대 10회)
		[신규] 소환수가 있는 동안 나 또는 내 소환수가 피해를 입히면 5초간 공명 1중첩 (최대 5중첩)
		[신규] 공명 1중첩당 내 피해 3%, 소환수 피해 6% 증가 (소환수가 모두 사라지면 공명도 사라집니다)

둠피스트:
	로켓 펀치:
		밀려난 적이 지형에 충돌할 때 피해: 밀어낸 피해의 150% -> 200%

쇼이치:
	비약:
		[신규] 이동 경로에 있는 단검을 주워, 이동이 끝나면 주운 수만큼 단검을 던집니다(범위 피해·재사용대기시간 초기화 없음)
		대상을 지정하지 않으면 다른 쇼이치의 단검으로도 이동하던 버그 수정
	협상:
		둔화 지속시간: 3초 -> 1.5초
		단검 생성 위치: 적중한 곳 -> 적의 뒤쪽
		[신규] 표식 대상은 던져진 단검으로 받는 피해 25% 증가
		[신규] 표식 대상이 던져진 단검에 맞을 때마다 재사용대기시간 1초 감소
		[신규] 표식 대상이 사망하면 재사용대기시간 90% 감소

울트라마린:
	기본 능력치:
		체력: 500 -> 600
	파워아머:
		남은 체력에 비례해 얻는 방어력: 최대 30 -> 최대 50
		방어력 증가: 최대 1.5배 -> 최대 2배
	분쇄:
		피해: 40(+10% 추가 체력)(+45% 방어력) -> 30(+8% 추가 체력)(+20% 방어력)
		재사용대기시간: 7초 -> 9초
	방어:
		반격 피해(한손 무기): 50(+50% 공격력) -> 50(+30% 공격력)
	갑주돌격:
		피해: 30(+5% 추가 체력)(+25% 방어력) -> 10(+5% 추가 체력)(+8% 방어력)
	처형:
		처형 성공 시 회복: 잃은 체력의 50% -> 30%

레이센:
	단시「초단뇌파(X-웨이브)」:
		사거리: 16 -> 20
		파동 속도: 15 -> 20
		분신의 기본공격 피해·적중 효과: 100% -> 50%
