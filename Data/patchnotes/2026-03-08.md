# 게임캐릭터배틀
source: https://gall.dcinside.com/mgallery/board/view?id=steve&no=372465

증강:

 이제 인벤토리에서 클릭해서 교체하면 위치를 바꿀 수 있습니다

 네셔의이빨:
 공격속도: 50% -> 30%

 헤르메스시미터:
 재사용대기시간: 25초 -> 30초
 이제 사용 후 1초간 저지불가 상태가 됩니다

 겐지:
 리워크됨

 기본공격:
 점사 간격: 0.15초 -> 0.1초

 질풍참:
 피해량: 40(+50% 공격력) -> 50(+100% 추가 공격력)
 초기화 기준: 플레이어 처치시 -> 아무거나 처치하면

 이즈리얼:
 사거리: 40 -> 60

 신비한 화살:
 시전시간: 0.25초 -> 0.15초
 시전 후 0.1초 후딜레이 추가됨
 [삭제] 시전중 이동속도 감소 50%

 정수의 흐름:
 사거리: 64 -> 80

 정조준일격:
 추가 공격력 계수: 120% -> 150%
 타격력 계수: 150% -> 200%

 울트라마린:
 처형:
 시전시간: 1초 -> 0.75초

 엘렌:
 기본공격:
 이제 전방 90도의 대상을 자동으로 찾습니다

 리바이:
 거인학살:
 최대 피해량 증가: 200% -> 250%

 가르기:
 이제 평캔 가능

 입체기동:
 이동속도: 24m/s -> 30m/s

 루시안:
 기본공격:
 투사체 폭: 1 -> 1.25
