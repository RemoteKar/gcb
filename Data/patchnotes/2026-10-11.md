# 게임캐릭터배틀

게임진행:
	부활:
		대기시간: 30초에서 사망마다 2배 -> 40초에서 사망마다 2배 (40초 / 80초 / 160초)
		최소 대기시간: 30초 -> 10초
		처치당 다음 부활 대기시간 감소: 15% -> 20%
		부활 후 느린 낙하: 2초 -> 1초
		부활 후 대상 지정 불가: 5초 -> 3초 (착지하면 바로 해제)
	킬 회복:
		즉시 회복: 최대체력의 10% -> 25%
		지속 회복: 6초간 최대체력의 20% -> 10초간 최대체력의 25%

코어:
	바위의 신의 눈:
		보호막: 4초간 최대체력의 15% -> 1초간 최대체력의 5%
		보호막 유지 중 방어력 증가: 10(+5% 최대체력)(+10% 방어력) -> 12(+6% 최대체력)(+15% 방어력)

바랄:
	기본 능력치:
		체력: 650 -> 600
		공격력: 60 -> 50
		공격속도: 0.75 -> 0.6
	무력화:
		되돌려주는 피해: 받은 피해의 40% + 기본공격 피해 -> 받은 피해의 10% + 기본공격 피해
		재사용대기시간: 24초 -> 30초
	C:
		치유 차단: 7초 -> 3.5초
