# 게임캐릭터배틀
source: https://gall.dcinside.com/mgallery/board/view?id=steve&no=252565

자기장:
 150초 이후의 자기장의 피해량이 큰폭으로 증가(약 2배)

 증강:
 자폭:
 피해량: 최대체력의 50% -> 45%
 범위: 16 -> 12

 보석 건틀릿:
 기본확률: 20% -> 25%
 피해량: 125% -> 130%

 잭:
 BT:
 [신규 로드아웃] 톤
 탐지 및 유도 투사체 병기를 사용하는 공격적인 로드아웃

 뱅가드:
 다중목표미사일시스템:
 이제 미사일이 회전시 한번에 회전할수있는 각도제한이 있음(무빙으로 피하기 쉬워짐)
 이제 미사일이 발사 후 타겟을 찾는게 아닌 스킬시전즉시 타겟을 정함
 피해량: 25 -> 30

 제이스:
 무기 모델링이 새것으로 바뀜

 탈론:
 갈퀴손:
 피해량: 150 -> 180

 둠피스트:
 라이징어퍼컷:
 재사용대기시간: 6초 -> 9초

 유령:
 무기 모델링이 새것으로 바뀜
 공격력 40 -> 35
 저격:
 에너지소모: 7 -> 8

 렌서:
 게이볼그:
 피해량: 250 -> 300

 크산테:
 길을 여는 자:
 가로충돌범위: 3 -> 3.5
 최소돌진거리: 3 -> 6

 총공세:
 재사용대기시간: 60초 -> 70초
 피해량: 50 -> 75
 충돌피해량: 50 -> 75
 기절: 0.5초 -> 0.75초

 스모커:
 뭉개뭉개열매:
 대상지정불가: 0.75초 -> 1초

 손흥민:
 황제팽귄2호:
 유도성능이 증가함

 마리사:
 체력: 300 -> 400
 공격속도: 0.75 -> 0.8

 [연부] 마스터스파크:
 범위: 2.5 -> 3

 스페셜리스트:
 익시드:
 더이상 저지불가의 영향을 받지 않음
 둔화: 75% -> 25%
 당기는 중력의 힘이 약 17% 감소 (0.12 -> 0.1)
 신규[중력500배]: 블랙홀 내부에서 시전하는 모든 이동기의 속도가 65% 감소함

 캬루:
 데드 엔드 커스:
 시전시간: 1.1초 -> 0.8초
 속박시간: 3초 -> 1.75초

 롤랑:
 휠스인더스트리:
 신규: 기절 0.75초

 이즈리얼:
 끓어오르는 주문의 힘:
 중첩당 공격속도: 14% -> 15%
