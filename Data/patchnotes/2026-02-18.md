# 게임캐릭터배틀
source: https://gall.dcinside.com/mgallery/board/view?id=steve&no=370428

게임진행관련:
 킬 힐: 처치 즉시 최대체력의 20% + 10초간 20%회복 -> 처치 즉시 최대체력의 20% + 10초간 30%회복
 이제 킬 회복은 자기장의 불태우기 회복량 감소 -50%에 영향을 받지 않음

 점령구역:
 활성화 시간: 100초 -> 40초

 증강:
 가시갑옷:
 발동조건: 피해를 입으면 -> 기본공격에 피해를 입으면

 자기장:
 피해량: 게임 시간에 비례,초당 최대체력의 0.1%~10% -> 게임 시간에 비례,초당 최대체력의 0.1%~3%

 초당피해량증가: 1.02배 -> 1.05배

 최대피해량 기준 버틸수 있는 시간이 기존 약 90초에서 50~70초로 감소함 (피해량이 초당 최대체력의 약 50%이상에 도달하는 시간)

 이제 킬 회복은 자기장의 불태우기 회복량 감소 -50%에 영향을 받지 않음

 스페셜리스트:
 익시드:
 피해량: 160(+200% 추가공격력)(+150% 타격력) -> 175(+150% 추가공격력)(+200% 타격력)
 사거리: 40 -> 50

 라이트닝 슬래쉬:
 타격력계수: 1.2 -> 1.8

 일렉트릭 필러:
 타격력계수: 0.75 -> 0.8
 사거리: 32 -> 40

 트러블슈터:
 인크레더블:
 피해량: 300(+300% 추가공격력)(+600% 타격력) -> 300(+400% 추가공격력)(+800% 타격력)

 탈론:
 이동속도: 5.5 -> 7.0
 체력재생: 4 -> 5

 피닉스:
 체력: 500 -> 400
 보호막축전기:
 재사용대기시간: 8초 -> 10초

 정화 개시:
 유도가 작동 안하는 문제 해결

 사일러스:
 강탈:
 유도가 작동 안하는 문제 해결

 아이작:
 체력: 700 -> 600
 착취:
 피해량: 30(+40% 공격력)(+대상최대체력의 4%) -> 20(+25% 공격력)(+대상최대체력의 5%)

 크산테:
 엔토포 타격:
 방어력 계수: 0.4 -> 0.6
 재사용대기시간: 3 -> 2.5

 길을 여는 자:
 방어력계수: 5% -> 10%

 엘렌:
 체력: 400 -> 500

 급랭충전:
 스킬로 적에게 피해를 가하면 1스텍 -> 스킬을 사용하거나 스킬로 적에게 피해를 가하면 1스텍

 사냥순행:
 재사용대기시간: 11초 -> 6초
 이제 유닛 처치시 재사용대기시간이 초기화 됩니다

 리신:
 음파/공명의일격:
 피해량: 50(+120% 추가공격력) -> 40(+100% 추가공격력)

 폭풍:
 피해량: 50(+100% 공격력) -> 30(+100% 공격력)

 아카츠키:
 체력: 600 -> 500
 공격력: 40 -> 30

 전광기관:
 중첩의 유지시간: 10초 -> 6초

 특공:
 재사용대기시간: 4초 -> 5초

 인간 박격포:
 피해량: 60(+60% 추가 공격력) -> 40(+75% 공격력)

 신풍:
 재사용대기시간: 40초 -> 50초
 적중 좌우 폭: 2칸 -> 1칸

 후레쉬맨:
 체력: 600 -> 500

 매그너스:
 강타:
 기절: 2.5초 -> 2초

 피해량: 40(+120% 공격력) -> 20(+110% 공격력)

 폭주 바이크:
 체력계수: 40% 최대체력 -> 30%추가체력

 울트라마린:
 파워아머:
 방어력: 40 -> 100
 짧은 점프 재사용대기시간: 4초 -> 3초

 점프팩:
 비행 중 이동속도 감소: 60% -> 0%

 점프공격:

 최대 시전 각도: 30도 -> 20도 (도약공격 사거리 약 9% 증가)
 이제 비행시 점프공격의 조준된 지점이 표시됩니다

 처형:
 사거리: 8 -> 10

 바랄:
 무력화:
 피해 반사: 받은피해의 50%(+100% 공격력) -> 받은피해의 25%(+100% 공격력)

 혈청W:
 피해량: 20(+25% 공격력)(+40% 타격력) -> 16(+20% 공격력)(+40% 타격력)

 캡틴팔콘:
 팔콘펀치:
 피해량: 120(+250% 추가 공격력) -> 150(+300% 추가 공격력)

 개굴닌자:
 물수리검:
 최대 차징시 피해량 증가: 200% -> 100%
