# 게임캐릭터배틀

게임진행:
	자동 시작:
		대기 시간: 60초 -> 45초

증강:
	정령의형상:
		받는 회복·보호막 효과 증가: 35% -> 25%

코어:
	응급 심장:
		받는 회복 효과 증가: 50% -> 30%
		체력이 낮을 때: 체력 30% 이하에서 100% -> 체력 25% 이하에서 60%

히로빈:
	UNSTOPABLEERROR:
		모든 적에게 걸리는 화면 지직거림이 크게 약해집니다
		돌진 대상에게만 기존의 강한 화면 효과가 나옵니다

사쿠야:
	나이프(기본공격):
		빨강 나이프 피해: 각각 15% 공격력 -> 각각 20% 공격력
		파랑 나이프 피해: 각각 10% 공격력 -> 각각 15% 공격력
		빨강 나이프 개수: 추가 공격속도 100%당 +1 -> 80%당 +1
		파랑 나이프 개수: 추가 공격속도 66%당 +1 -> 55%당 +1
	환부「살인 인형」:
		빨강 나이프 피해: 각각 2(+12% 추가 공격력)(+8% 타격력) -> 각각 3(+18% 추가 공격력)(+12% 타격력)
		파랑 나이프 피해: 각각 4(+12% 추가 공격력)(+8% 타격력) -> 각각 6(+18% 추가 공격력)(+12% 타격력)
		빨강 나이프 개수: 추가 공격속도 40%당 +1 -> 30%당 +1
		파랑 나이프 개수: 추가 공격속도 30%당 +1 -> 25%당 +1
	환장「밤안개의 환영살인귀」:
		돌진 피해: 20(+40% 추가 공격력)(+20% 타격력) -> 30(+60% 추가 공격력)(+30% 타격력)
		나이프 피해와 개수가 환부「살인 인형」과 같이 바뀝니다
	「사쿠야의 세계」:
		피해: 50(+쌓인 피해의 30%) -> 75(+쌓인 피해의 30%)

랜서:
	창술·시작의 철퇴:
		돌진 피해: 50(+50% 추가 공격력) -> 50(+50% 추가 공격력)(+30% 타격력)
		재시전 피해: 20(+100% 추가 공격력) -> 20(+100% 추가 공격력)(+30% 타격력)
	게이 볼그:
		피해: 200(+300% 추가 공격력)(+300% 타격력) -> 200(+300% 추가 공격력)(+400% 타격력)

바랄:
	C:
		고정 피해: 30(+110% 공격력) -> 20(+100% 공격력)
		회복 차단: 3.5초 -> 3초

노르마:
	기본 능력치:
		체력: 300 -> 400
	웅나 포탑:
		미사일 피해: 15(+35% 추가 공격력) -> 10(+25% 추가 공격력)

파이논:
	기본 능력치:
		이동속도: 5 -> 4.5
	이 몸을 횃불 삼아:
		불씨를 얻는 피해: 한 번에 100 이상 -> 한 번에 150 이상
		불씨당 추가 체력재생: 1 -> 0.5
	재앙·영혼과 천명의 소멸:
		반격에 더하는 피해: 방어 중 받은 피해의 75% -> 45%
	영원히 타오르는 세상, 그가 짊어지리라:
		변신 해제 때 블록을 부수는 범위: 20 -> 14 (바닥은 부수지 않습니다)

기타:
	마지막 결투와 최종 라운드의 하늘 효과를 임시로 껐습니다 (일부 유저의 화면이 하늘색으로 덮여 보이지 않던 문제)
	게임 시작 안내에 무적 시간이 숫자로 나오지 않던 버그 수정
