# 게임캐릭터배틀
source: https://gall.dcinside.com/mgallery/board/view?id=steve&no=261632

증강:
 탱커:
 방어력: 15 -> 20

 정복자:
 고정피해: 20% -> 25%

 삼위일체:
 공격력: 5 -> 10
 이동속도: 5% -> 10%

 도벽:
 천장 높이 증가, 전 구간 확률은 천장적용 이전보다 높다

 결의:
 방어력: 25 -> 30

 무라마나:
 피해량: 10 -> 15

 강인함:
 방해효과 감소: 60% -> 75%

 광휘:
 회복시간: 10초간 회복 -> 8초간 회복

 텝 댄서:
 스텍당 이동속도: 0.1 -> 0.05
 중첩 지속시간: 15초 -> 8초
 신규: 스텍당 공격속도 5% 증가

 총기:
 윙맨:
 탄폭: 0.15 -> 0.25

 피스키퍼:
 탄폭: 0.15 -> 0.25

 r301:
 탄폭: 0.15 -> 0.25
 조준시 둔화: 60% -> 50%

 네메시스:
 탄폭: 0.15 -> 0.25

 디보션:
 피해량: 14 -> 12
 탄폭: 0.25 -> 0.15

 마리사:
 체력: 400 -> 300
 공격속도: 0.8 -> 0.9
 마법을 쓰는 정도의 능력:
 사거리: 64 -> 50
 피해량: 50 -> 80
 폭: 1 -> 1.5

 마부 「스타더스트 레버리」:
 방해효과에 적중당할시 즉시 효과가 종료되고 재사용대기시간이 적용됨

 스페셜리스트:
 일렉트릭 필러:
 사거리: 20 -> 32

 웨펀마스터:
 극 귀검술 폭풍식:
 범위: 12 -> 16
 높이: 6 -> 10
 고정시간: 4초 -> 3초
 이제 시전 즉시 고정을 거는것이 아닌, 칼이 땅에 박힐떄 고정을 검
 이펙트 약간 변경

 아이작:
 추격 / 검거:
 기절시간: 0.65초 -> 1초

 헤이즈:
 산탄포화:
 선딜 약간 감소

 비나:
 사슬:
 속박: 1.5초 -> 0.75초
 사거리: 80 -> 100

 자물쇠:
 피해량: 65 -> 60

 겐지:
 공격력: 30 -> 20
 용검:
 피해량: 180 -> 240
 재사용대기시간: 90초 -> 60초

 세트:
 기본 체력재생: 3 -> 2

 피닉스:
 차원이동:
 재사용대기시간: 16초 -> 15초

 데스페라도:
 건호크:
 초당피해량: 80 -> 90

 패스파인더:
 그래플링훅:
 재사용대기시간: 15초 -> 10초

 가렌:
 결정타:
 피해량: 70 -> 80

 심판:
 피해량: 20 (200) -> 30 (300)
 범위: 3.5 -> 4

 크산테:
 총공세:
 잃는체력: 40% -> 30%
