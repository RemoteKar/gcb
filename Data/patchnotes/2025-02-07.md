# 게임캐릭터배틀 new 치르노
source: https://gall.dcinside.com/mgallery/board/view?id=steve&no=325032

자기장관련:
 줄어드는속도가 감소했습니다

 증강:
 점멸:
 재사용대기시간: 25초 -> 20초
 정화:
 재사용대기시간: 25초 -> 16초

 잭:
 BT로닌:
 리드월샷건:
 전탄기준 피해량: 120 -> 160

 에코:
 시간도약:
 추가피해량: 60 -> 40

 텐시:
 요석「카나메 판넬」:
 재사용대기시간: 10초 -> 15초

 나나야C키:
 극사나나야:
 피해량: 120 + 대상이 잃은체력의 100% -> 대상이 잃은체력의 100%

 호크아이:
 공격력: 80 -> 70

 기본공격:
 투사체 폭: 0.55 -> 0.9
 이제 호크아이의 기본공격의 차징 피해량이 선형적으로 증가하지 않고 x^2함수를 따름
 즉 반만 차징할시 기준 기존의 절반임 (0.5*2 = 0.25)
 최대 피해량은 같음

 관통화살:
 기본피해량: 60 -> 40
 총 공격력 계수: 1.5 -> 1.2

 신규: 이제 적중당한 적의 이동기를 종료시키고, 0.5초 기절시킴

 매의 주시:
 잔상효과가 더 명확하게 진해졌습니다
