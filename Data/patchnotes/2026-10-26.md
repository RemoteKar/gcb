# 게임캐릭터배틀

게임진행:
	자동 시작:
		대기 시간: 20초 -> 60초
		게임 시작 10초 전 연습장이 닫히면 안에 있던 플레이어가 로비로 빨려 나옵니다
	배경음악:
		로비와 연습장에서도 배경음악이 나옵니다
		캐릭터 전용 배경음악은 게임 중에만 나옵니다
	마지막 결투:
		(신규) 마지막 두 명만 남으면 하늘이 어두워지고 결투 배경음악이 나옵니다
	자기장:
		라운드 알림이 화면 대신 채팅으로 나옵니다
	연습장:
		공격 더미 체력: 10000 -> 1000

사쿠야:
	(리메이크) 캐릭터가 새로 리메이크되었습니다

겐지:
	기본 능력치:
		사거리: 60 -> 100
	사이보그닌자:
		스페이스바를 누르고 있어도 벽을 오릅니다
		(신규) 벽을 오르면 이단 점프를 다시 쓸 수 있습니다
	수리검(기본공격):
		(신규) 탄창 30발, 공격마다 3발 소모, 재장전 1.5초(공격속도와 무관)
		투사체 속도: 60 -> 75
	수리검(1번):
		피해: 각각 20% 공격력 -> 각각 기본공격과 같은 피해(33% 공격력)
		산탄 각도: 4 -> 4.5
		(신규) 탄환 3발 소모
		추가 공격속도가 높을수록 사용 간격이 지나치게 빨라지던 버그 수정
	질풍참:
		(신규) 용검 사용 중 피해 100% 증가
		판정 좌우 폭: 4 -> 3.5
		재사용대기시간 초기화 조건: 적 처치 -> 적 플레이어 처치
	용검:
		지속시간: 8초 -> 6초
		처치 시: 지속시간 4초 증가 -> 지속시간 6초로 초기화(적 플레이어 처치)
		재사용대기시간: 60초 -> 100초
		(신규) 가한 피해 1당 재사용대기시간 0.01초 감소 (궁극기 자체 피해와 궁극기 사용 중 가한 피해는 제외)

둠피스트:
	파멸의 일격:
		피해: 80(+100% 추가 공격력) -> 100(+120% 추가 공격력)
		중심 피해: 200(+250% 추가 공격력) -> 250(+300% 추가 공격력)
		재사용대기시간: 90초 -> 130초
		(신규) 가한 피해 1당 재사용대기시간 0.01초 감소 (궁극기 자체 피해와 궁극기 사용 중 가한 피해는 제외)

시그마:
	강착:
		적중한 적이 넘어지지(밀려나지) 않던 버그 수정
	중력 붕괴:
		재사용대기시간: 90초 -> 110초
		(신규) 가한 피해 1당 재사용대기시간 0.01초 감소 (궁극기 자체 피해와 궁극기 사용 중 가한 피해는 제외)

마우가:
	기본 능력치:
		체력: 800 -> 700
	케이지 혈투:
		재사용대기시간: 110초 -> 140초
		(신규) 가한 피해 1당 재사용대기시간 0.01초 감소 (궁극기 자체 피해와 궁극기 사용 중 가한 피해는 제외)

엑스칼리버:
	기본 능력치:
		체력: 500 -> 400

아카츠키:
	특공:
		피해량: 15(+80% 추가 공격력) -> 25(+80% 추가 공격력)

기타:
	여러 캐릭터의 처형·결정타·궁극기에 화면 효과 추가
	우승 화면에서 일부 캐릭터 초상화가 깨지거나 나오지 않던 버그 수정
