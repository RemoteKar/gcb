# 게임캐릭터배틀
source: https://gall.dcinside.com/mgallery/board/view?id=steve&no=335939

고참병의 흉터:
 추가체력: 125 + 총 체력1.25배 증가 -> 150 + 총 체력1.2배 증가

 판금장화:
 방어력: 10 -> 12
 기본공격피해량감소: 15% -> 20%

 양자폭발:
 피해량: 최대체력의 20% -> 25%
 발동하는 체력: 30% -> 40%

 액시옴 비전 마법사:
 처치시 궁극기 재사용대기시간 감소: 12% -> 18%

 월식:
 보호막: 50 -> 80

 샌즈:
 와샌즈:
 회피율 90% -> 96%

 이즈리얼:
 체력: 500 -> 400
 신비한 화살:
 피해량: 40(+1.5총공격력) -> 50(+1.6총공격력)
 적중 폭: 1.25 -> 0.8
 정수의 흐름:
 피해량: 100 -> 150
 적중 폭: 1.75 -> 1.2

 비전이동:
 재사용대기시간: 12 -> 9
 사거리: 15 -> 18

 헤이즈:
 공격력: 45 -> 60
 기관단총:
 피해량에 치명타가 적용되지 않는 버그를 수정함

 스타로드:
 스텔라 시프트:
 재사용대기시간: 5초 -> 6초

 리신:
 음파:
 적중 폭: 1.0 -> 1.2

 폭풍:
 피해량: 100 -> 90
 무력화:
 무력화 대상이 가하는 피해 감소: 25% -> 30%

 에이스:
 이글이글 열매:
 지정불가 시간: 0.75초 -> 0.6초

 크산테:
 체력: 700 -> 800
 이동속도: 4.5 -> 5.0

 세트:
 이동속도: 4.5 -> 5.0
 강펀치:
 기본피해량: 25 -> 40

 가렌:
 이동속도: 4.5 -> 5.0

 데스페라도:
 이동속도: 4.75 -> 5.0

 런처:
 체력재생: 3 -> 1
 이동속도: 4.75 -> 5.0

 웨펀마스터:
 이동속도: 4.75 -> 5.0
 발도:
 시전시간: 1초 -> 0.9초

 스페셜리스트:
 이동속도: 4.75 -> 5.0

 코스틱:
 체력: 300 -> 350

 히로빈:
 체력: 200 -> 300

 아처:
 칼라드볼그:
 피해량: 100 (+타격력미적용 대상최대체력의 30%) -> 120 (+타격력미적용 대상최대체력의 35%)

 무한의검제:
 재사용대기시간: 150초 -> 130초

 요네:
 필멸의 검:
 재사용대기시간 감소: 추가공격속도 40%에서 최대 -> 30%에서 최대

 영혼가르기:
 재사용대기시간 감소: 추가공격속도 40%에서 최대 -> 30%에서 최대

 운명봉인:
 피해량: 125 x2 -> 75(+2.0추가공격력) x2

 엘렌:
 이빨 전지법:
 이제 Y축 이동을 초기화 시키지 않음(중력의 영향을 받음)
 돌진 거리: 1+(1.0기본공격사거리)(5) -> 0+(1.0기본공격사거리)(4)
 돌진 속도: 30m/s -> 24m/s (돌진하는데 걸리는 총 시간은 기존과 같음)
 대쉬 중 시전시 돌진거리 증가: 70% -> 50%

 사냥 순행:
 기절: 1초 -> 0.25초
