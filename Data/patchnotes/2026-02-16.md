# 게임캐릭터배틀 시즌4 베타 5시반
source: https://gall.dcinside.com/mgallery/board/view?id=steve&no=370192

그래픽:
 스킬 쉐이딩 방식 변경
 약간 더 진해짐

 게임 진행 관련:
 게임 시간이 약 8분으로 늘어남
 그에따라 라운드 수도 9라운드로 늘어남

 킬 회복:
 30초간 잃은체력의 75% -> 즉시 최대체력의 20% 회복 + 10초간 최대체력의 20%회복

 점령구역:
 곳곳에 점령구역이 등장합니다
 게임 시작후 100초 후 활성화 됩니다
 활성화된 점령구역에 혼자서 20초간 혼자 있으면 점령하여
 보상으로 무작위 스텟을 얻습니다
 스텟은 무슨스텟인지 점령구역에 써있습니다

 이렇게 얻은 스텟은 사망시 사라지며 처지자에게 그대로 전달됩니다

 자기장:
 이제 기본 피해량은 게임 시간에 비례하여 초당 최대체력의 0.1%~10% 임
 이제 자기장에 맞을수록 피해량은 초당 1.02배식 무한히 더 강해짐

 이제 자기장의 피해량보다 체력이 낮을시 한번 체력 1로 버팀
 이 효과는 10초에 한번 발동함

 증강:
 이제 증강은 게임 시작전 선택 할 수 없습니다

 게임 시작후 60,120,180,240초에 하나식 포인트를 얻어 구매할 수 있습니다

 증강페이지는 명령어 or 게임중에는 기존의 캐릭터 선택 페이지 버튼을 눌러 열 수 있습니다

 똑똑한장화:
 사용증강 재사용대기시간 감소 -> 모든증강 재사용대기시간 감소
 감소율 40% -> 30%

 넉백관련:
 이제 넉백은 강넉백과 약넉백으로 나뉨

 강넉백은 기존이랑 같고

 약넉백은 밀리는건 똑같은데 채널링을 끊지도 않고 이동기,강넉백을 캔슬시키지도 못하고 스킬도 써지는 넉백입니다

 약넉백의 CC기 서열은 둔화랑 같습니다

 약넉백시에는 KNOCKBAKING ui가 나오지 않습니다

 옥테인:
 자극제:
 지속시간중 스텝업 효과 추가
 이동속도: 100% -> 70%

 죠타로:
 알려진 버그들 수정
 스탠드를 꺼내는 시간: 0.6초 -> 0.5초
 스타플라티나:
 피해주기: 초당5회 -> 10회

 사쿠야:
 공격력: 50 -> 40
 기본공격의 피해량이 이제 각각 20%로 나눠지는게 아니라
 한개에만 적중해도 최대피해량을 입힙니다
 투사체 여러개에 적중해도 피해량은 중첩되지않습니다

 롤랑:
 휠스인더스트리:
 기절: 0.6초 -> 1초

 시그마:
 공격력: 35 -> 50
 기본공격의 투사체 속도: 85m/s -> 50m/s
 이제 기본공격 적중시 주변 적을 중앙으로 약간 당겨옴
 기본공격 이펙트 변경

 런처:
 미라클 비전:
 뽑아치기의 범위: 3 -> 4

 아카츠키:
 특공:
 이제 1,2,3번째 시전은 약 넉백임

 신풍:
 이제 약넉백임

 아처:
 로 아이아스:
 이제 피해와 그 후속 효과를 완전히 막음

 이즈리얼:
 신비한 화살:
 사거리: 64 -> 80
 투사체 속도 10%정도 감소
 투사체 폭 10%정도 감소

그외 캐릭터들 전체 계수와 깡딜 변경
